### 📦 Run Locally

Clone the repository and start the development server.

git clone https://github.com/25abubakar/My-Portfolio.git
cd My-Portfolio

npm install --legacy-peer-deps
npm run dev

Open in browser:

http://localhost:3000
---
### Requirements

Node.js v16 – v20

### 🏗️ Production Build

To create an optimized production build:

npm run build
