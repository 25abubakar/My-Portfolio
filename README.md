## 📦 Run Locally

```bash
# Clone the repo
git clone https://github.com/25abubakar/muhammad-abubakar-portfolio.git
cd muhammad-abubakar-portfolio

# Install dependencies
npm install --legacy-peer-deps

# Start development server
npm run dev
```

> Requires **Node.js v16–v20**. Opens at `http://localhost:3000`

---

## 🏗️ Build for Production

```bash
npm run build
```

Output goes to `/build` folder — ready to deploy on GitHub Pages, Netlify, or Vercel.
